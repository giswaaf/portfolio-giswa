Comparative Analysis of Naive Bayes and DistilBERT Models for Spam Email Detection

This project compares a classical text-classification baseline with a transformer-based model to distinguish spam emails from legitimate messages (ham). It examines traditional feature engineering alongside contextual language representations.

RoleMachine learning research
FocusText classification · NLP · Model comparison
Open project files ↗

Project materials are shared in Google Drive.

Two approaches to text classification

The baseline uses Multinomial Naive Bayes with TF-IDF features to represent email text through weighted terms. The comparison model uses DistilBERT, which can use context across a message rather than relying only on independent word weights.

Reported evaluation

The project materials report that DistilBERT achieved 99% accuracy and a 0.95 F1-score, outperforming the baseline in the reported experiment. These values depend on the dataset and testing setup.

From prediction to inference

The selected model is connected to an inference pipeline that classifies incoming messages and returns a confidence score alongside the predicted label, making the output easier to inspect in an email filtering workflow.
