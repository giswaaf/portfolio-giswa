Face Attendance

FaceAttend is an automated attendance platform built around face recognition and anti-spoofing checks. It aims to make attendance recording practical while helping reduce check-ins using a photo, screen, or mask.

RoleApplication design and development
FocusFace recognition · Anti-spoofing · Attendance
View GitHub repository ↗

A more reliable attendance flow

The project brings identity verification and attendance recording into one experience. Face recognition supports the check-in flow, while anti-spoofing measures are intended to reject common presentation attempts such as printed photos and images shown on a screen.

Two user perspectives

FaceAttend includes dedicated dashboards for teachers and students, giving each group a focused place to use attendance information and helping keep tracking and management together.

Project focus

The work explores how computer vision can support academic processes through convenient attendance tracking, clearer access to attendance data, and a more secure check-in experience.
